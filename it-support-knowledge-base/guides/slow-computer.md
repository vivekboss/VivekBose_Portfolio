# 🐢 Slow Computer

## Steps
1. **Restart** the PC (many users never do).
2. **Task Manager** (`Ctrl+Shift+Esc`): check CPU, memory, disk and network usage; identify the heavy process.
3. **Startup apps:** Task Manager → Startup tab → disable unnecessary items.
4. **Storage:** Check free space on C: drive; run Disk Cleanup / Storage Sense.
5. **Updates:** Install pending Windows and driver updates.
6. **Malware scan:** Run Windows Security full scan.
7. **Check hardware health:** Disk status, RAM size, overheating or dust.
8. **Escalate:** Recommend an SSD or RAM upgrade, or a reimage, if issues persist.
